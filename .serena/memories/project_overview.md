# Project Overview
- Purpose: Notes/Forester project with a Python CLI (`forester-rag`) for RAG indexing and content generation over `.tree` notes.
- Stack: Python 3.12, Poetry, Typer CLI, Pydantic, OpenAI SDK, pytest, ruff, black. Also includes JS/TS assets for notes site tooling.
- Important roots: `src/` (Python package), `scripts/` (utility scripts), `tests/`, `trees/`, `docs/`, `Makefile`.

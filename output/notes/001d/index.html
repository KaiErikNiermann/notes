Definition. Terminal Object (Category Theory) [001d]

  • November 23, 2025

In category theory, a terminal object (or final object) in a category \(\mathcal C\) is an object \(T\) such that for every object \(X\) in \(\mathcal C\), there exists a unique morphism \(f : X \to T\). In other words, a terminal object is an object that can be reached from any other object in the category via a unique morphism.

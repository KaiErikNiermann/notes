Definition. Injective, Surjective & Bijective (Sets)

  • November 29, 2025

A function \(f : X \to Y\) is called injective (or one-to-one) if for every pair of elements \(x_1, x_2 \in X\) the following holds:

\[ f(x_1) = f(x_2) \implies x_1 = x_2 \]

A function \(f : X \to Y\) is called surjective (or onto) if for every element \(y \in Y\) there exists an element \(x \in X\) such that:

\[ f(x) = y \]

A function \(f : X \to Y\) is called bijective if it is both injective and surjective. In this case there exists an inverse function \(f^{-1} : Y \to X\) such that the following hold:

\[ f^{-1}(f(x)) = x \quad f(f^{-1}(y)) = y \]

In the categorical sense a bijection is just an isomorphism in a 0-category (i.e. the category of sets). We can give an equivalent more pedantic definition of bijectivity as follows:

\[ \forall y \in Y.\ (f(f^{-1}(y)) = y \land \forall x \in X.\ (f(y) = x \to f^{-1}(x) = y)) \]

Definition. VC's for functions [004s]

  • December 13, 2025

Let's start by informally describing the syntax of functions: 


  fn f(x1, ..., xn) {
    requires (P)
    ensures  (Q)
    modifies (v1, ..., vk)
    s;
    return e;
  }

Then for function calls we have: 


  x := f(e1, ..., en)

1. Verifying function definitions

  • December 13, 2025

The central idea with function definitions is that we assume the preconditions \(P\) and assert the post-conditions \(Q\), what this means in a practical sense is that when verifying the function body what we actually must verify is:

\[ \texttt {assume}(P);\ s;\ \texttt {ret} := e;\ \texttt {assert}(Q) \]

The idea being that by this convention a function contract - the requires, ensures, modifies specification - internally assumes that the caller has met the necessary pre-conditions and provides as a guarantee the required post-conditions.

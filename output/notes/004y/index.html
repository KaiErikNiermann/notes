Definition. Constrained Horn clauses [004y]

  • December 16, 2025

We define \(\mathcal {C}\) to be a set of constrained Horn clauses such that

\[ \mathcal {C} \triangleq \{C_1, \ldots , C_n\} \]

there are two important properties we should consider

  • We say that a query \(r\) depends on a query \(q\) if there is some clause \(C \in \mathcal {C}\) such that \(q\) appears in \(C\)'s body and \(r\) appears in \(C\)'s head.
  • We say that a set of horn clauses \(\mathcal {C}\) is recursive if at least one predicate directly or indirectly depends on itself. Formally, if we consider a sequence of horn clauses \[ C_1, C_2, \ldots , C_k \] such that the head of some clause \(C_i\) depends on the body of some clause \(C_{m}\) and the head of \(C_k\) depends on the body of \(C_i\) then we have a cycle which makes the set \(\mathcal {C}\) recursive. As an example let's define a set of horn clauses to characterize transitive closure. \[ \begin {align} \texttt {reach}(x, y) &\gets \texttt {edge}(x, y) \\ \texttt {reach}(x, z) &\gets \texttt {reach}(x, y) \land \texttt {reach}(y, z) \end {align} \]

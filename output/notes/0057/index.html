Definition. Constrained clause [0057]

  • December 17, 2025

Let \(\mathcal L\) be a first-order language. A constrained clause is a formula \(C\) of the form

\[ \phi \land \bigvee _{i = 1}^m \neg X_i(\bf t_i) \land \bigvee _{j = 1}^n Y_j(\bf s_j) \]

where:

  • (\(\phi \)) is a first-order formula in \(L\)
  • (\(X_i, Y_j\)) are predicate variables, i.e. denote placeholders for relations
  • (\(\bf t_i, \bf s_j\)) are tuples of terms in \(L\)

the formula \(C\) is denoted...

  • Horn, if \(n \leq 1\)
  • dual-Horn, if \(m \leq 1\)
  • linear-Horn, if \(m, n \leq 1\)

commonly we talk about sets of constrained clauses \(S\), these sets denote conjunctions of clauses and are thus equivalent to the formula

\[ \forall ^* \land _{C \in S} \equiv S \triangleq \{C_1, C_2, \ldots , C_n\} \]

The formula \(\exists \bf X \forall ^*_{C \in S} C\) is called

  • A Horn formula, if \(S\) is a set of CHC
  • A dual-Horn formula, if \(S\) is a set of CdHC
  • A linear-Horn formula, if \(S\) is a set of ClHC

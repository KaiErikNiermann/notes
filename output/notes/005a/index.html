Definition. Verifying Hoare triples with wp horn clauses [005a]

  • December 19, 2025

We start off with our usual Hoare triple:

\[ \{P\}\ s\ \{Q\} \]

In the context of Horn clauses the typical idea is that as opposed to computing the weakest precondition as we have done before we solve for it based off a system of constraints over predicate variables. What this means practically speaking is that we introduce a predicate variable AKA query \(p(\overline x)\). We then define

\[ \texttt {wp}(s, p(\overline x)) = p'(\overline e) \]

The important observation here is that there are 3 main constraints which emerge from this computation

  • The first is the precondition constraint \[ P \to p'(\overline x) \]
  • The second is the postcondition constraint, since our weakest precondition computation is based on a synthesized unknown predicate variable we must ensure we can use postcondition weakening to ensure compatibility with our postcondition \(Q\) \[ Q \to p(\overline x) \]
  • Finally we also have our set of constraints generated by the \(\texttt {wp}\) computation itself. As a reminder when we talk about \(\texttt {wp}\) for the case of horn clauses we are talking about the synthesis of a predicate variable or query characterized by a system of constraints. We can denote this set of constraints as the set of horn clauses \(\mathcal C\).

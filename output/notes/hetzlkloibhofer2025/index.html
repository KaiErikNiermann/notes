    Definition. Universal closure w.r.t variables [0058]

    • December 17, 2025

    If a formula \(C\) has a set of free variables:

    \[ \texttt {FV}(C) = \{x_1, x_2, \ldots , x_n\} \]

    Then we can denote the universal closure \(\forall ^*\) as representing the universal quantification over all those free variables, i.e. (1):

    \[ \forall ^* C \equiv \forall x_1, x_2, \ldots , x_n.\ C \]
